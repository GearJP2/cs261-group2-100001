## ยอดเครดิตและ ledger

`credit_score` เป็นยอดตั้งต้นที่ใช้จริงบวกผลของ events หลังจากนั้น ไม่ใช่ผลรวม `delta` อย่างเดียว เมื่อเริ่มจาก NULL: ตั้งฐาน 100 โดยไม่มี event ตั้งต้น แล้วเพิ่ม delta (-5) ใน transaction เดียวกับ event จึงได้ credit_score=95 ขณะที่ผลรวม ledger=-5 เป็นพฤติกรรมที่รับไว้โดยชัดแจ้ง

หากมีเครดิตเดิมก่อนใช้ ledger ให้ถือยอดเดิมเป็น opening balance ไม่ใช้ฐาน 100 ทับยอดเดิม การกระทบยอดจึงต้องทราบ opening balance ด้วย ไม่มี API กระทบยอดหรือบันทึก event ตั้งต้นเพิ่มในงานนี้ มตินี้แทนข้อเสนอเดิมของ D-6 และกฎ 13 เฉพาะ US14 เครดิตความประพฤติ แยกจากค่าเฉลี่ยดาว

## เงื่อนไขส่งมอบ

- ไม่เปลี่ยนสูตรหรือ logic ที่ผ่าน tests เดิม และไม่เปิด flag ในรอบนี้
- ปิด flag ไม่ย้อนรายงานหรือเครดิตที่เคย commit แล้ว
- Migration ยังคงสร้างตารางแม้ flag ปิด; flag ควบคุม HTTP endpoint ไม่ใช่ schema
- การยืนยัน policy ไม่ใช่หลักฐานว่า manual API/UI/UAT ผ่าน งาน tests ที่เคย Blocked ต้อง retest ก่อนตรวจรับส่วนนั้น
